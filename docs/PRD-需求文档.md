# 课题组财务管理系统 - 产品需求文档（PRD）

## 1. 产品概述

### 1.1 背景
学术课题组日常涉及大量财务工作：经费管理、报销审批、发票处理、采购流程等。目前多采用纸质+微信群沟通，效率低、易出错、难追溯。

### 1.2 目标用户
- **学生**：提交报销、采购申请
- **导师**：审批、查看经费概况
- **财务助理**：处理报销、发票管理
- **管理员**：系统配置、权限管理

### 1.3 核心价值
- 流程线上化，审批透明可追踪
- 发票电子归档，支持查重
- 经费实时统计，预算可控
- 移动端友好，随时随地操作

---

## 2. 功能模块

### 2.1 用户与权限

| 角色 | 权限 |
|------|------|
| 学生 | 提交报销/采购申请、查看个人记录 |
| 财务助理 | 处理报销、管理发票、查看统计 |
| 导师 | 审批申请、查看所有数据、经费管理 |
| 管理员 | 用户管理、系统配置、权限分配 |

**功能点**：
- 用户注册/登录（支持邀请码注册）
- 个人信息维护
- 角色切换（一人多角色场景）

### 2.2 经费管理

**功能点**：
- 经费项目台账（项目名称、来源、金额、余额、有效期）
- 经费到账登记
- 经费支出统计（按项目/时间/类别）
- 预算设置与预警
- 结题提醒

**字段设计**：
```
项目名称 | 项目编号 | 经费来源(纵向/横向) | 总金额 | 已用金额 | 余额 | 负责人 | 起止时间 | 状态
```

### 2.3 报销管理

**流程**：
```
学生发起 → 上传票据 → 导师审批 → 财务处理 → 财务受理 → 完成
                ↓
            驳回修改 ←─────────┘
```

**功能点**：
- 报销申请表单
  - 报销类型（差旅/采购/版面费/其他）
  - 金额、摘要、经费项目选择
  - 上传票据（支持多张）
- 审批功能（通过/驳回+原因）
- 进度追踪（状态时间线）
- 报销记录查询（多条件筛选）
- 批量导出

**状态流转**：
| 状态 | 说明 |
|------|------|
| 草稿 | 未提交 |
| 待审批 | 已提交，等待导师审批 |
| 审批通过 | 导师已通过 |
| 财务处理中 | 财务助理处理中 |
| 已受理 | 学校财务已受理 |
| 已打款 | 完成 |
| 已驳回 | 需修改重新提交 |

### 2.4 发票管理

**功能点**：
- 发票录入（手动/OCT识别）
- 发票归档（电子发票存储）
- 发票查重（防止重复报销）
- 发票统计（按月份/类型）
- 开票申请（横向项目对外开票）

**发票字段**：
```
发票代码 | 发票号码 | 开票日期 | 购买方 | 销售方 | 金额 | 税额 | 价税合计 | 类型 | 关联报销单
```

### 2.5 采购管理

**流程**：
```
申请 → 审批 → 采购 → 验收 → 入库/报销
```

**功能点**：
- 采购申请（设备/耗材/服务）
- 审批流程
- 采购订单跟踪
- 到货验收
- 固定资产登记

### 2.6 差旅管理

**功能点**：
- 出差申请（行程、预算）
- 差旅标准校验（交通/住宿标准）
- 差旅报销（关联出差申请）
- 出差统计

### 2.7 统计报表

**功能点**：
- 经费使用概况（仪表盘）
- 支出分析（按类别/项目/时间）
- 报销统计（按人/按项目）
- 导出Excel

### 2.8 系统设置

**功能点**：
- 报销类别配置
- 审批流程配置
- 差旅标准设置
- 通知设置（邮件/微信）

---

## 3. 非功能需求

### 3.1 性能要求
- 页面加载 < 2秒
- 支持50+并发用户

### 3.2 安全要求
- 用户认证（JWT）
- 数据加密存储
- 操作日志记录
- 定期数据备份

### 3.3 可用性
- 响应式设计（支持手机/平板/电脑）
- 操作引导提示
- 错误信息友好

---

## 4. 开发优先级

### P0（MVP核心功能）
1. 用户登录注册
2. 经费项目台账
3. 报销申请与审批
4. 发票录入与查重
5. 基础统计

### P1（第二阶段）
1. 采购管理
2. 差旅管理
3. 消息通知
4. 导出报表

### P2（第三阶段）
1. 发票OCR识别
2. 移动端App
3. 与学校系统对接

---

## 5. 成功指标

- 报销处理周期缩短 50%
- 发票重复报销率降至 0
- 经费数据实时可查
- 用户满意度 > 80%
